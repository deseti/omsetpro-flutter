# Logo Assets

Simpan file logo Omset Pro dengan nama `omsetpro_logo.png` di folder ini.

File yang diperlukan:
- `omsetpro_logo.png` - Logo utama aplikasi (minimal 1024x1024 pixels untuk kualitas terbaik)

Setelah menyimpan logo, jalankan perintah:
```
flutter pub get
flutter pub run flutter_launcher_icons:main
```
